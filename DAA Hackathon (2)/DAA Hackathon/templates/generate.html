DAA Algorithm Characteristics & Guarantees

Constructs conflict interference graph $G=(V, E)$ where vertices represent class sessions and edges represent mutual exclusivity (shared faculty, batch, or lab hardware). Colors correspond to discrete time slots. Welsh-Powell orders vertices by degree descending and greedily assigns the lowest valid color, calculating the chromatic number $\chi(G)$.

Orders classes using Most Constrained Variable (MCV) criteria (Labs first, High Priority, highest student strength). Greedily assigns each class to the earliest available valid time slot and room with minimal penalty. Records any unscheduled classes.

Systematically explores the combinatorial solution space. Assigns slots to classes recursively. If any hard constraint fails, it undos the decision (backtracks) to explore alternative choices. Guarantees finding a complete conflict-free solution if one exists.
